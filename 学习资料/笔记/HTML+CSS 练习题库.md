## 第二部分 判断题

*判断对错，错的要能说出错在哪里。*

**1.** HTML 标签名不区分大小写，属性名和属性值也不区分大小写，但都推荐小写。

**2.** 一个标签中可以写两个同名属性，两个都会生效。

**3.** 【查看网页源代码】看到的是程序员编写的源代码，【检查】看到的是浏览器处理后的源代码。

**4.** HTML 注释可以嵌套使用。

**5.** 网页存储时用什么编码，读取时就必须用什么解码，否则会出现乱码。

**6.** 编码时应该统一采用 GBK，因为它是收录汉字最多的字符集。

**7.** 元素的默认效果不重要，语义才是最重要的。

**8.** 块级元素中几乎什么都能写，行内元素中也能写块级元素。

**9.** 一个元素的 class 属性可以写多个值，多个值之间用空格隔开。

**10.** 一个元素可以同时拥有 id 和 class 属性。

**11.** 相对路径中的 `./` 可以省略不写。

**12.** 使用网络绝对路径引入图片时，若服务器开启了防盗链，会造成图片引入失败。

**13.** gif 格式支持透明背景，也支持动态图，但仅支持 256 种颜色。

**14.** webp 格式兼具多种格式的优点，但兼容性不太好。

**15.** 多个空格、多个回车在网页中会被浏览器解析成多个空格。

**16.** `a` 元素可以包裹除它自身外的任何元素。

**17.** 表格的 `border` 属性值可以控制单元格边框的宽度。

**18.** 给某个 `td` 设置了宽度之后，它所在那一列的宽度就确定了。

**19.** 应该用 `<br>` 来增加文本之间的行间隔。

**20.** 行内样式、内部样式、外部样式三者的优先级是：行内 > 内部 = 外部。

**21.** 同一个样式表中，后面的样式会覆盖前面的样式。

**22.** 通配选择器 `*` 的权重高于元素选择器。

**23.** 并集选择器的权重计算时，每一个部分是分开算的。

**24.** 继承样式时，优先继承离得近的祖先元素。

**25.** `border`、`background`、`padding`、`margin` 这些属性都可以被继承。

**26.** 元素的默认样式优先级高于继承的样式。

**27.** `line-height` 的值可以为负数。

**28.** `vertical-align` 可以控制块元素的垂直对齐。

**29.** `padding` 的值不能为负数，`margin` 的值可以为负数。

**30.** 行内元素的左右内边距可以完美设置，上下内边距不能完美设置。

**31.** 行内元素可以完美设置四个方向的 margin。

**32.** 给块级元素设置左右 `margin` 都为 `auto`，可以让它在父元素中水平居中。

**33.** margin 合并问题需要通过给父元素设置 `overflow:hidden` 来解决。

**34.** `visibility:hidden` 隐藏元素后，元素依然占据原来的位置。

**35.** 浮动元素会脱离文档流，且不会发生 margin 合并和 margin 塌陷。

**36.** 浮动元素的父元素宽度依然能够束缚浮动的元素。

**37.** 相对定位会脱离文档流，并对其他元素产生影响。

**38.** 绝对定位元素与浮动同时设置时，浮动生效，以浮动为主。

**39.** 粘性定位不会脱离文档流，最常用的值是 top。

**40.** 只要设置了 `z-index` 就能调整元素的显示层级。

**41.** 发生相对定位后，元素依然是之前的显示模式；发生绝对定位后，元素变成"定位元素"。

**42.** 重置默认样式时，`Normalize.css` 比 `reset.css` 更温和，会保留一些有价值的默认样式。

**43.** CSS3 的 `opacity` 和 `rgba()` 作用完全一样。

**44.** `background-size:contain` 可能会造成容器里部分区域没有背景图片。

**45.** `outline-offset` 是 `outline` 的子属性。

**46.** 线性渐变 `linear-gradient(red,yellow,green)` 默认从左到右渐变。

**47.** 2D 位移与相对定位都不脱离文档流，但位移的百分比参考的是自身，相对定位的百分比参考的是父元素。

**48.** 多重变换时，建议把旋转写在最后。

**49.** `perspective` 要设置给发生 3D 变换元素本身。

**50.** `backface-visibility` 需要加在发生 3D 变换元素的自身上。

**51.** 所有 CSS 属性都支持过渡。

**52.** `animation-play-state` 一般单独使用。

**53.** 伸缩容器的所有后代元素都会成为伸缩项目。

**54.** 无论原来是块元素、行内元素还是行内块元素，一旦成为伸缩项目，全都会"块状化"。

**55.** 改变了 flex 主轴的方向后，侧轴方向不会改变。

**56.** `flex:1` 等价于 `flex:1 1 auto`。

**57.** `flex-grow` 的默认值是 0，`flex-shrink` 的默认值是 1。

**58.** 媒体查询中 `orientation:portrait` 表示视口处于横向。

**59.** BFC 能解决子元素的 margin 塌陷、自身被浮动元素覆盖、以及子元素浮动导致的高度塌陷。

**60.** `display:flow-root` 可以开启 BFC。

### 第三部分 名词解释

**1. 超文本/标记/标记语言**：超文本指比普通文本内容更丰富的文本；标记指让文本变成超文本所需的各种标记符号；标记的写法、读音、使用规则组成了标记语言。  
**2. 语义化**：用特定的标签去表达特定的含义。原则是标签的默认效果不重要，语义最重要。优势：结构清晰可读性强、有利于 SEO、方便设备解析。  
**3. 块级/行内/行内块**：块级独占一行、默认宽度撑满父元素、可设宽高；行内不独占一行、默认宽高由内容撑开、不能设宽高；行内块不独占一行、默认宽高由内容撑开、可设宽高。  
**4. 锚点**：网页中的一个标记点，可通过 `a` 的 `name` 属性或其他标签的 `id` 属性设置，用 `href="#锚点名"` 跳转。  
**5. 相对路径/绝对路径**：相对路径以当前位置为参考点建立路径（`./`、`../`）；绝对路径以根位置为参考点，分本地绝对路径与网络绝对路径。  
**6. 层叠性**：发生样式冲突（同一元素的同一样式名被设置不同值）时，按选择器优先级进行覆盖。  
**7. 继承性**：元素自动拥有父元素或祖先元素上设置的某些样式，优先继承离得近的。可继承的是不影响布局的属性（字体、文本、颜色等）。  
**8. 选择器权重**：不同选择器选中同一元素并设置同一样式名时决定谁生效的依据，格式为 (a,b,c)。  
**9. 像素**：电脑屏幕由一个个"小点"组成，每个小点就是一个像素；像素点越小，呈现内容越清晰细腻。  
**10. 盒子模型**：CSS 把每个 HTML 元素都看成一个盒子，由 margin、border、padding、content 四部分组成。  
**11. margin 塌陷**：第一个子元素的上 margin 会作用在父元素上，最后一个子元素的下 margin 会作用在父元素上。  
**12. margin 合并**：上面兄弟元素的下外边距和下面兄弟元素的上外边距会合并，取最大值而非相加。  
**13. 清除浮动**：消除浮动元素对后续兄弟元素和父元素（高度塌陷）造成的影响。  
**14. 包含块**：没脱离文档流的元素，包含块是父元素；脱离文档流的元素，包含块是第一个拥有定位属性的祖先元素（都没有则整个页面）。  
**15. 定位元素**：绝对/固定定位后的元素，默认宽高被内容撑开，且能自由设置宽高。  
**16. 视口**：对 PC 浏览器来说，就是看网页的那扇"窗户"，固定定位参考视口。  
**17. 版心**：PC 端网页中固定宽度且水平居中、用于显示主要内容的盒子，宽度一般 960~1200px。  
**18. 幽灵空白问题**：行内块元素与文本的基线对齐，而文本基线与文本最底端之间有一定距离，导致行内块底部出现空隙。  
**19. BFC**：块级格式上下文，可理解为元素的一个"特异功能"，默认关闭，满足某些条件后被激活（创建了 BFC）。  
**20. 怪异盒模型**：`box-sizing:border-box`，此时 width 和 height 设置的是盒子总大小，而非内容区大小。  
**21. 私有前缀**：W3C 提出的某个 CSS 特性在被浏览器正式支持之前，浏览器厂商用私有前缀来测试该特性；正式支持后就不需要了。  
**22. 变换原点**：元素变换时的基准点，默认在元素中心，用 `transform-origin` 设置；对位移无影响，对旋转和缩放有影响。  
**23. 景深**：指定观察者与 z=0 平面的距离，能让 3D 变换的元素产生透视效果，显得更立体，用 `perspective` 设置。  
**24. 帧/关键帧**：一段动画中连续播放的每一张画面叫帧；若干帧中起到决定性作用的 2~3 帧叫关键帧。  
**25. 伸缩容器/伸缩项目**：开启 flex 的元素是伸缩容器；伸缩容器的所有子元素自动成为伸缩项目。  
**26. 主轴/侧轴**：伸缩项目沿主轴排列，主轴默认水平、方向从左到右；与主轴垂直的是侧轴，默认垂直、从上到下。  
**27. 字体图标**：用字体文件呈现图标，相比图片更清晰、灵活性高（可改大小颜色风格）、兼容性好。  
**28. 媒体查询**：通过检测设备类型和媒体特性（如视口宽度）来应用不同样式的技术，是实现响应式布局的基础。

### 第四部分 简答与对比题（要点）

**1.** C/S 需安装、偶尔更新、不跨平台、开发更具针对性；B/S 无需安装、无需更新、可跨平台、开发更具通用性。前端工程师主要负责 B/S 架构网页。  
**2.** 五大浏览器：Chrome、Safari、IE、Firefox、Opera。前缀：Chrome/Safari/Edge 用 `-webkit-`，Firefox 用 `-moz-`，旧 Opera 用 `-o-`，旧 IE 用 `-ms-`。  
**3.** ASCII 128 个（字母数字符号）；ISO 8859-1 共 256 个（扩充希腊字符等）；GB2312 收录 6763 个常用汉字 + 682 个字符；GBK 汉字符号 20000+ 且支持繁体；UTF-8 包含世界上所有语言的文字与符号。原则：①存储时务必采用合适的字符编码，否则数据丢失；②存储时用什么编码，读取时就用什么解码，否则乱码。  
**4.** `lang` 作用：让浏览器显示对应的翻译提示、有利于搜索引擎优化。zh-CN 中文-中国大陆；zh-TW 中文-中国台湾；en-US 英语-美国。  
**5.** 见知识点总结"标准结构"。`head` 内容不会出现在网页中，`body` 中内容才会呈现。  
**6.** jpg：有损压缩，颜色丰富、体积小、不支持透明和动态，用于产品宣传图；png：无损、支持透明、质量高，用于 logo 和重要配图；bmp：不压缩、细节多、体积极大，用于大型游戏图片；gif：仅 256 色、支持简单透明和动态，用于网页动态图；webp：兼具优点但兼容性差，用于网页各种图片；base64：图片编码成文本，直接作为 src 值，不受文件位置影响，用于较小图片。  
**7.** ①让搜索引擎得知图片内容（最主要）；②图片无法展示时浏览器呈现 alt 值；③盲人阅读器朗读 alt 值。  
**8.** ①跳转到指定页面 `<a href="https://www.jd.com/">`；②跳转到指定文件（可触发下载）`<a href="./x.zip">`；③跳转到锚点 `<a href="#test1">`；④唤起指定应用 `<a href="tel:10010">`。  
**9.** 有序列表 `ol>li`，用于有顺序或侧重顺序的内容；无序列表 `ul>li`，用于无顺序的内容；自定义列表 `dl>dt+dd`，用于术语名 + 术语描述，一个 dt 可对应多个 dd。  
**10.** 表格标题 caption、表格头部 thead、表格主体 tbody、表格脚注 tfoot。`th` 是表头单元格（文字默认加粗居中），`td` 是普通单元格；二者属性相同。  
**11.** text 文本、password 密码、radio 单选、checkbox 复选、hidden 隐藏域、submit 提交、reset 重置、button 普通按钮、file（文件）等。  
**12.** 由 `&` + 实体名称（或 `#` + 实体编号）+ `;` 组成。空格 `&nbsp;`、小于号 `&lt;`、大于号 `&gt;`、和号 `&amp;`、版权 `&copy;`、乘号 `&times;`、除号 `&divide;`。  
**13.** 字符编码、IE 兼容性、移动端 viewport、关键字 keywords、描述 description、爬虫规则 robots、作者 author、生成工具 generator、版权 copyright、自动刷新 refresh。  
**14.** 优势：针对 JS 新增很多可操作接口、新增语义化标签与全局属性、新增多媒体标签替代 flash、更侧重语义化对 SEO 更友好、可移植性好适合移动设备。兼容性：Chrome/Safari/Opera/Firefox 均支持；IE 必须 9 及以上，且 IE9 仅支持部分新特性。  
**15.** ①一个 article 里可以有多个 section；②section 强调分段分块；③article 更强调独立性、完整性。  
**16.** `meter` 定义已知范围内的标量测量（电量、磁盘用量），属性 high/low/max/min/optimum/value；`progress` 显示任务完成进度，属性 max（目标值）、value（当前值）。  
**17.** placeholder（文字输入类控件，非默认值）、required（除按钮外其他控件）、autofocus（所有表单控件）、autocomplete（文字输入类，密码框和多行输入框不可用）、pattern（文本输入类，多行输入不可用，空值不验证，常与 required 配合）。  
**18.** none 不预加载；metadata 仅预先获取元数据（如长度）；auto 可以下载整个文件。若使用 autoplay，则忽略 preload。  
**19.** ①添加 `<meta http-equiv="X-UA-Compatible" content="IE=Edge">` 让浏览器处于最优渲染模式；②用 html5shiv 让低版本浏览器认识 H5 语义化标签（配合条件注释）；③加 `<meta name="renderer" content="webkit">` 优先使用 webkit 内核渲染。  
**20.** 见知识点总结"三种编写位置"表格。优先级：行内 > 内部 = 外部，同级"后来者居上"。  
**21.** 基本选择器：通配、元素、类、ID；复合选择器：交集、并集、后代、子代、兄弟（相邻/通用）、属性、伪类、伪元素。  
**22.** 交集：`选择器1选择器2{}`，含义"并且"；有标签名必须写在最前；不会出现两个元素选择器；最常用"元素 + 类"。并集：`选择器1,选择器2{}`，含义"或者"；一般竖着写；任何选择器都可作为其中一部分；常用于集体声明。  
**23.** 父元素（直接包裹某元素的元素）、子元素（被父元素直接包含）、祖先元素（父亲的父亲……）、后代元素（儿子的儿子……）、兄弟元素（具有相同父元素）。  
**24.** 后代选择器 `A B{}` 选中 A 中所有符合条件的后代（儿子、孙子都算）；子代选择器 `A>B{}` 只选中 A 的直接子元素。  
**25.** `[属性名]` 具有该属性；`[属性名="值"]` 属性值等于；`[属性名^="值"]` 以该值开头；`[属性名$="值"]` 以该值结尾；`[属性名*="值"]` 包含该值。  
**26.** 伪类选中元素的一种特殊状态（像类但不是类），伪元素选中元素中的一些特殊位置。伪类：:link/:visited/:hover/:active/:focus/:first-child/:nth-child()/:not()/:checked/:disabled 等；伪元素：::first-letter/::first-line/::selection/::placeholder/::before/::after。  
**27.** 顺序 :link → :visited → :hover → :active。`:focus` 只有表单类元素才能使用；点击、触摸、tab 键选中元素时即获得焦点。  
**28.** ①0 或不写：什么都选不中；②n：选中所有子元素；③1~正无穷整数：选中对应序号；④2n 或 even：偶数；⑤2n+1 或 odd：奇数；另有 -n+3 选中前 3 个。  
**29.** (a,b,c)：a = ID 选择器个数，b = 类/伪类/属性选择器个数，c = 元素/伪元素选择器个数。ul>li (0,0,2)；div ul>li p a span (0,0,6)；#atguigu .slogan (1,1,0)；#atguigu .slogan a (1,1,1)；#atguigu .slogan a:hover (1,2,1)。比较时从左到右逐位对比。  
**30.** `!important` > 行内样式 > ID > 类 > 元素 > `*` > 继承的样式。并集选择器的每个部分分开算权重。  
**31.** 颜色名、rgb/rgba、HEX/HEXA、HSL/HSLA。开发中常用 rgb/rgba 与 HEX/HEXA。  
**32.** 字体大小、字体族必须都写；字体族必须是最后一位、字体大小必须是倒数第二位；各属性用空格隔开。  
**33.** normal（浏览器根据文字大小决定）、px、数字（自身 font-size 的倍数，最常用）、百分比。设置 height 时高度就是 height 的值；不设置 height 时根据 line-height 计算高度。  
**34.** 见知识点总结"显示模式"表格。块元素例：div/p/h1、ul/ol/li、table/tr；行内元素例：br/em/strong、a/label；行内块例：img、td/th、input/button、iframe。  
**35.** none 隐藏；block 按块级显示；inline 按内联显示；inline-block 按行内块显示。  
**36.** 盒子大小 = content + 左右 padding + 左右 border；总宽度 = 父的 content − 自身的左右 margin；内容区宽度 = 父的 content − 自身左右 margin − 自身左右 border − 自身左右 padding。margin 不影响盒子大小，但影响盒子位置。  
**37.** 1 个值：四方向相同；2 个值：上下 / 左右；3 个值：上 / 左右 / 下；4 个值：上 / 右 / 下 / 左（顺时针）。  
**38.** 塌陷：子元素 margin 作用到父元素上，解决：父元素设非 0 padding 或非 0 宽度 border，或 `overflow:hidden`。合并：相邻兄弟上下 margin 取最大值，无需解决，只给一个设即可。  
**39.** visible 显示、hidden 隐藏、scroll 总是显示滚动条、auto 自动。`overflow-x` 与 `overflow-y` 不能一个 hidden 一个 visible，属实验性属性，不建议使用。  
**40.** `visibility:hidden` 看不见但仍占位；`display:none` 彻底隐藏，不占位、没有大小宽高。  
**41.** 元素间空白：行内/行内块元素之间的换行被解析为空白字符，解决：去掉换行（不推荐）或父元素 `font-size:0` 再给文字元素单独设字体大小（推荐）。幽灵空白：行内块与文本基线对齐导致底部空隙，解决：设置 `vertical-align` 不为 baseline、或图片 `display:block`、或父元素 `font-size:0`。  
**42.** 水平居中：块元素 → 自己 `margin:0 auto`；行内/行内块 → 父元素 `text-align:center`。垂直居中：块元素 → 自己 `margin-top = (父 content − 子盒子总高)/2`；行内/行内块 → 父元素 height = line-height，子元素 `vertical-align:middle`。  
**43.** 特点：脱离文档流；默认宽高由内容撑开且可设宽高；不独占一行；不会 margin 合并/塌陷，能完美设置四方向 margin 和 padding；不会被当作文本处理。影响：后面的兄弟元素会占据浮动元素之前的位置，显示在其下面；父元素不能被撑开导致高度塌陷，但父元素宽度依然束缚浮动元素。  
**44.** ①给父元素指定高度；②给父元素也设置浮动；③父元素 `overflow:hidden`；④在所有浮动元素最后加块级元素并 `clear:both`；⑤给父元素设置伪元素清除浮动（推荐）。原理同④，通过伪元素 `content:""; display:block; clear:both;` 实现。  
**45.** 见知识点总结"定位"表格。  
**46.** 没脱离文档流的元素，包含块是父元素；脱离文档流的元素，包含块是第一个拥有定位属性的祖先元素（都没有则整个页面）。  
**47.** 用于调整元素显示层级；值是数字无单位，值越大层级越高；只有定位的元素设置才有效；若层级没生效，检查其包含块的层级。  
**48.** 宽充满：`left:0; right:0;`；高充满：`top:0; bottom:0;`。居中方案一：`left:0;right:0;top:0;bottom:0;margin:auto;`（必须设置宽高）；方案二：`left:50%;top:50%;margin-left:-宽度一半;margin-top:-高度一半;`。  
**49.** 版心：固定宽度且水平居中的盒子，宽度一般 960~1200px。布局名词：topbar 顶部导航条、header/page-header 页头、nav/navbar 导航、search-box 搜索框、banner 横幅、content/main 主要内容、aside/sidebar 侧边栏、footer/page-footer 页脚。  
**50.** 全局选择器：简单案例可用，但会重置所有元素且不能做特定处理，实际开发不用；reset.css：选择到有默认样式的元素清空其样式，重置后网页像"一张白纸"；Normalize.css：在清除默认样式基础上保留有价值的默认样式，更温和，并提供 HTML5 元素设置。  
**51.** 更实用的选择器、更好的视觉效果（圆角/阴影/渐变）、丰富的背景效果、弹性盒子、Web 字体、增强的颜色（HSL/HSLA/RGBA、opacity）、2D/3D 变换、动画与过渡。  
**52.** content-box（默认）：width/height 设置的是内容区大小；border-box：width/height 设置的是盒子总大小（怪异盒模型）。border-box 更适合需要精确控制盒子占位的布局场景。  
**53.** `box-shadow: h-shadow v-shadow blur spread color inset`——水平位置、垂直位置（前两个必须写）、模糊距离、外延值、颜色、内阴影；`text-shadow: h-shadow v-shadow blur color`——水平位置、垂直位置（必须写）、模糊距离、颜色。  
**54.** `opacity` 是属性，设置整个元素（包括内容）的不透明度；`rgba()` 是颜色设置方式，其透明度仅调整颜色的透明度。  
**55.** `background-origin` 设置背景图的原点，默认 padding-box；`background-clip` 设置背景图向外裁剪的区域，默认 border-box，取值为 text 时需加 `-webkit-` 前缀。  
**56.** 长度值：指定大小（不允许负值）；百分比：按容器比例（不允许负值）；auto：图片真实大小（默认）；contain：等比缩放使图片完整包含在容器内，可能有留白；cover：等比缩放到完全覆盖容器，图片可能显示不完整，是相对更好的选择。  
**57.** `background: color url repeat position / size origin clip`。origin 和 clip 若只写一个值则两者都设置，写两个值时前面是 origin、后面是 clip；size 必须写在 position 后面并用 `/` 分开。  
**58.** `border-radius: 左上x 右上x 右下x 左下x / 左上y 右上y 右下y 左下y`。一个值是正圆半径；两个值分别是椭圆的 x 半径、y 半径。  
**59.** normal 超出自动换行、文本中换行被识别为空格（默认）；pre 原样输出；pre-wrap 在 pre 基础上超出自动换行；pre-line 超出自动换行且只识别换行、忽略空格；nowrap 强制不换行。text-overflow 生效条件：块容器、overflow 非 visible、white-space 为 nowrap。  
**60.** 线性渐变默认从上到下，可用关键词（to top / to right top）或角度（30deg）控制方向；径向渐变默认从圆心四散，用 `at 位置` 调整圆心、用 `circle` 或半径值调整形状。重复渐变：`repeating-linear-gradient` 与 `repeating-radial-gradient`，参数同前。  
**61.** `@font-face { font-family:"名字"; src:url('字体文件'); }`。字体图标优点：比图片更清晰、灵活性高（方便改大小颜色风格）、兼容性好。  
**62.** 位移改变位置、缩放放大缩小、旋转顺时针/逆时针转动、扭曲把元素"拉扯"变形。多重变换时若先旋转，后续位移会沿旋转后的坐标轴进行，容易与预期不符，所以建议最后旋转。  
**63.** 开启 3D 空间 `transform-style:preserve-3d` 写在父元素上；景深 `perspective` 也写在父元素上（发生 3D 变换元素的父元素）；背部可见性 `backface-visibility` 写在发生 3D 变换元素的自身。  
**64.** ease 平滑（默认）、linear 线性、ease-in 慢→快、ease-out 快→慢、ease-in-out 慢→快→慢、step-start 等同 steps(1,start)、step-end 等同 steps(1,end)、steps(整数,start|end) 步进函数、cubic-bezier(n,n,n,n) 贝塞尔曲线。  
**65.** 一个时间表示 duration，两个时间分别是 duration 和 delay，其他属性无数量和顺序要求。子属性：animation-name 指定动画、animation-duration 时长、animation-delay 延迟、animation-timing-function 类型、animation-iteration-count 次数、animation-direction 方向、animation-fill-mode 动画外状态、animation-play-state 播放状态（一般单独使用）。  
**66.** 过渡需要触发条件（如 hover），只在两个状态之间平滑变化；动画用 @keyframes 定义多个关键帧，可以自动播放、循环、指定次数和方向，无需触发条件。  
**67.** `justify-content` 控制主轴对齐；`align-items` 控制侧轴对齐（一行）；`align-content` 控制侧轴对齐（多行）。justify-content：flex-start/flex-end/center/space-between/space-around/space-evenly；align-items：flex-start/flex-end/center/baseline/stretch；align-content：flex-start/flex-end/center/space-between/space-around/space-evenly/stretch。  
**68.** `flex-basis` 主轴方向的基准长度（默认 auto，会让宽或高失效）；`flex-grow` 放大比例（默认 0）；`flex-shrink` 压缩比例（默认 1）。`flex` 默认 `0 1 auto`；`flex:auto` = 1 1 auto；`flex:1` = 1 1 0；`flex:none` = 0 0 auto。  
**69.** `order` 定义项目排列顺序，数值越小越靠前，默认 0；`align-self` 单独调整某个项目的对齐方式，默认 auto（继承父元素 align-items）。  
**70.** `@media 媒体类型 and (媒体特性) { ... }`。运算符：and 并且、, 或、not 否定、only 肯定。结合外部样式：①`<link rel="stylesheet" media="具体媒体查询" href="x.css">`；②在 CSS 文件内用 @media 包裹。  
**71.** BFC 即块级格式上下文，可理解为元素的一个"特异功能"，默认关闭，满足条件后被激活。解决：①子元素不再产生 margin 塌陷；②自身不会被其他浮动元素覆盖；③子元素浮动时自身高度也不会塌陷。开启方式：根元素、浮动元素、绝对/固定定位元素、行内块元素、表格单元格（table/thead/tbody/tfoot/th/td/tr/caption）、overflow 不为 visible 的块元素、伸缩项目、多列容器、`column-span:all` 的元素、`display:flow-root`。

### 第七部分 综合实操题（实现要点自查）

**1. PC 端首页**：版心 1200px + `margin:0 auto`；先做 reset（`* { margin:0; padding:0; }` 或引入 reset.css / Normalize.css）；三栏用浮动或 flex；用浮动时要给父元素清除浮动（伪元素方案）。  
**2. 响应式卡片列表**：flex + `flex-wrap:wrap`；用媒体查询切换 `flex-basis`（4 / 2 / 1 张）；标题用 `text-overflow:ellipsis`；hover 用 `transform:scale()` + `box-shadow` + `transition`。  
**3. 注册页**：用 header/main/footer 等语义标签；表单用 placeholder、required、autofocus、pattern（手机号 `^1[3-9]\d{9}$`）、email、tel、date、color、range；整体 `display:flex; justify-content:center; align-items:center; min-height:100vh`。  
**4. 个人名片（3D）**：父元素 `transform-style:preserve-3d` + `perspective`；正反面绝对定位重叠；背面先 `rotateY(180deg)`；两个面都加 `backface-visibility:hidden`；hover 时父元素 `rotateY(180deg)`，配 `transition`。  
**5. 数据展示页**：table 用 caption/thead/tbody 结构并含 rowspan/colspan；progress 用 max+value；meter 用 min/max/low/high/optimum/value；多列用 `column-count` + `column-gap` + `column-rule`；details+summary 做折叠；整体 flex 布局 + 媒体查询适配。
